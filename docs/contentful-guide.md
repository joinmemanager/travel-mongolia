# Contentful дээр контент нэмэх заавар

> Travel Hub Mongolia-гийн контент оруулагчид зориулав. Огноо: 2026-10-06.

Энэ заавар **малчин өрх, хөтөч, туршлага, нийтлэл, арга хэмжээ** нэмэх аргыг тайлбарлана. Contentful дээр талбар бүрийн доор жижиг саарал тайлбар байдаг. Эргэлзвэл түүнийг уншаарай.

## 1. Ерөнхий дараалал

1. Contentful-д нэвтэрч **Content → Add entry** дарна.
2. Төрлөө сонгоно (доорх хүснэгт).
3. Талбаруудыг бөглөнө. Улаан од (*)-той талбар заавал бөглөгдөнө.
4. Зургаа хавсаргана (5-р хэсэг).
5. **Publish хийхээс өмнөх шалгалтыг** хийнэ (7-р хэсэг).
6. **Publish** дарна. Сайт дээр шууд гарна, хуудсаа сэргээгээд шалгаарай.

**Холбоос хадгалдаг төрлүүдийг дарааллаар нь нэмнэ.** Жишээ нь туршлага "Зохион байгуулагч" талбараараа малчин өрх рүү холбогддог. Тиймээс малчин өрхийг эхэлж нэмж, publish хийнэ.

| Юу нэмэх вэ | Contentful-ын төрөл | Сайт дээр хаана гарах |
|---|---|---|
| Малчин өрх, хөтөч, гар урлаач, хоол, жижиг бизнес, байр | **Нутгийн үйлчилгээ үзүүлэгч (Local Provider)** | `/local/<slug>` + ангиллын хуудас |
| Туршлага (малчин айлд өнжих, эсгий хийх г.м.) | **Нутгийн туршлага (Community Experience)** | `/local/experiences/<slug>` |
| Нутгийн бүтээгдэхүүн (ааруул, эсгий шаахай г.м.) | **Нутгийн бүтээгдэхүүн (Local Product)** | `/local/products` |
| Нийтлэл, түүх, фото/видео түүх | **Нийтлэл, түүх (Story)** | `/stories/<slug>` + `/stories` |
| Баяр наадам, арга хэмжээ | **Арга хэмжээ, баяр наадам (Event)** | `/recommendation/<slug>` + `/things-to-do/festivals` |
| Газарт мөрдөх ёс, байгаль, аюулгүй байдлын зөвлөмж | **Аялагчийн зөвлөмж (Visitor Guidance)** | Тухайн газрын хуудасны "Хэрхэн зөв аялах" хэсэг |

> `/local/*` болон `/stories/*` хуудсууд одоогоор **ноорог (draft)** төлөвтэй. Тэд зөвхөн preview дээр харагдана. Үндсэн сайтад гаргах шийдвэрийг цэсний тохиргоогоор (`lib/navigation.ts`) тусад нь гаргана.

## 2. Малчин өрх, хөтөч (Local Provider)

| Талбар | Заавал | Тайлбар |
|---|---|---|
| Нэр | ✔ | Жишээ: Цэцгээгийн малчин айл |
| Slug | ✔ | 4-р хэсгийг үзнэ үү. Жишээ: `tsetsgeegiin-malchin-ail` |
| Төрөл | ✔ | Малчин өрх (`herder-family`), хөтөч (`guide`), гар урлаач (`artisan`), хоол (`food`), жижиг бизнес (`small-business`), байр (`accommodation`) |
| Аймаг | зөвлөмж | Ангиллын хуудасны шүүлтүүрт ашиглагдана. Нэрийг бүх entry-д ижил бичнэ (Архангай, Хөвсгөл). |
| Хэн бэ (түүх) | зөвлөмж | 2–4 догол мөр |
| Үйлчилгээ | зөвлөмж | Нэг бүрийг бичээд Enter дарна |
| Үнэ (-аас эхлэн) | — | Жишээ: 120,000₮ / хүн / хоног |
| Захиалгын холбоос | — | Хоосон бол "Захиалах" товч **joinme.mn** руу очно |
| Холбоо барих | — | Зөвхөн тухайн хүний зөвшөөрөлтэй бол |
| Нутгийн өмчлөлтэй | — | "Yes" бол **Нутгийн үйлчилгээ үзүүлэгч** тэмдэг гарна |
| Нутгийн оролцоо | — | Бичсэн бол **Нутгийн иргэдэд түшиглэсэн** тэмдэг гарна |
| Хариуцлагатай дадал | — | Бичсэн бол **Хариуцлагатай дадал** тэмдэг гарна |
| Хүлээн зөвшөөрөгдсөн гэрчилгээ | — | Бичсэн бол **Хүлээн зөвшөөрөгдсөн гэрчилгээ** тэмдэг гарна |
| Тусгай зөвшөөрөл | хөтөч, байрт | Хуулиар шаардлагатай лиценз |
| Эмэгтэйчүүд / залуучууд удирддаг | — | |
| Зураг | зөвлөмж | Эхний зураг нүүр зураг болно |

**Тэмдэгүүд зөвхөн бодит мэдээлэлтэй үед гарна.** "Eco", "green", "community-based" зэрэг үгийг нотолгоогүйгээр бичихгүй (стратеги баримт бичгийн 13-р хэсэг). Хариуцлагатай дадалд бодитоор хийдэг зүйлийг бичнэ. Жишээ нь "Хуванцар савгүй", "6 хүртэлх хүнтэй бүлэг".

## 3. Туршлага, бүтээгдэхүүн, нийтлэл, арга хэмжээ

**Туршлага (Community Experience).** Заавал бөглөх талбарууд: Гарчиг, Slug. "Зохион байгуулагч" талбарт эхлээд нэмсэн малчин өрх эсвэл хөтчөө сонгоно. "Юу хийх, мэдрэх вэ" хэсэгт өдрийн дарааллыг бичнэ. "Соёлын зөв харилцаа" хэсэгт оролцогч юуг анхаарах ёстойг бичнэ: гэрт орох ёс, зураг авах зөвшөөрөл гэх мэт.

**Бүтээгдэхүүн (Local Product).** Заавал бөглөх талбарууд: Нэр, Slug. "Үйлдвэрлэгч" талбарт хийдэг өрх эсвэл гар урлаачаа сонгоно. Бүтээгдэхүүнд тусдаа хуудас байхгүй. `/local/products` жагсаалтаас үйлдвэрлэгчийн профайл руу холбогдоно.

**Нийтлэл (Story).** Заавал бөглөх талбарууд: Гарчиг, Slug, Сэдэв.
- **"Зөвшөөрөл авсан" талбарыг "Yes" болгоогүй нийтлэл сайт дээр гарахгүй.** Аман түүх, зан үйл, хүний зургийг нийтлэхийн өмнө тухайн хүн, өрхөөс зөвшөөрөл авна.
- Эх сурвалж, хариуцсан редактор, шинэчилсэн огноог заавал бичихийг зөвлөж байна.
- Видеог YouTube эсвэл Vimeo-д байршуулаад холбоосыг нь "Видео холбоос" талбарт тавина.

**Арга хэмжээ (Event).** Заавал бөглөх талбарууд: Гарчиг, Slug.
- Эхлэх огноо бөглөвөл жагсаалт огноогоор эрэмбэлэгдэнэ. Нэг өдрийн арга хэмжээнд Дуусах огноог хоосон орхино.
- "Нутгийн үйлчилгээ" талбарт тэр үеэр үйлчилгээ үзүүлэх нутгийн өрх, хөтчийг сонгоно.
- Хуучин "Recommendation" төрлийн 4 наадам ч `/things-to-do/festivals` дээр хамт гарна.

**Аялагчийн зөвлөмж (Visitor Guidance).** "Газар" талбарт газар, өв эсвэл аймгийг сонгоно. Зөвлөмж бүрийг тусад нь бичээд Enter дарна. Тухайн газрын хуудсанд "Хэрхэн зөв аялах" хэсэг автоматаар гарна.

## 4. Slug хэрхэн бичих

Slug бол хаягт харагдах нэр, жишээ нь `travelhubmongolia.com/local/tsetsgeegiin-malchin-ail`.

- Зөвхөн **латин жижиг үсэг, тоо, зураас (-)** ашиглана. Хоосон зай, кирилл үсэг, том үсэг, цэг бичихгүй.
- Нэрийг латинаар галиглана. Ихэвчлэн хэрэглэгддэг үсгүүд:

| Кирилл | Латин | | Кирилл | Латин | | Кирилл | Латин |
|---|---|---|---|---|---|---|---|
| х | kh | | ө, ү, у | u | | ц | ts |
| ч | ch | | ш | sh | | ж | j |
| я | ya | | ё | yo | | е | ye |
| ы | y | | й, и | i | | ь, ъ | (бичихгүй) |

  Жишээ: Хөвсгөл нуур → `khuvsgul-nuur`, Цэцгээгийн айл → `tsetsgeegiin-ail`.
- **Давхардуулахгүй.** Нэг төрөлд ижил slug байж болохгүй. Contentful өөрөө анхааруулна.
- **Publish хийсний дараа slug-ийг өөрчлөхгүй байхыг хичээнэ.** Өөрчилбөл хуучин холбоос ажиллахаа больж, Google дахин index хийх хэрэгтэй болно.
- Нутгийн үйлчилгээ үзүүлэгчийн slug-д `guides`, `herder-families`, `artisans`, `food`, `products`, `experiences` гэсэн үгсийг ашиглахгүй. Эдгээр нь ангиллын хуудасны хаяг.

## 5. Зураг

- **Хэлбэр:** JPG (гэрэл зураг), хэвтээ, 3:2 эсвэл 4:3 харьцаатай.
- **Хэмжээ:** өргөн нь хамгийн багадаа **1600 px**, файлын хэмжээ 2 MB-аас ихгүй. Сайт зургийг автоматаар жижигрүүлдэг.
- **Эхний зураг нүүр зураг болж**, хуудасны дээд хэсэгт ба картанд харагдана. Гол объект нь зургийн голд байх хэрэгтэй, учир нь картанд зургийн ирмэг тайрагдана.
- Asset бүрт **Title**-д тайлбар бичнэ. Жишээ: "Архангайн малчин айлын гэр". Энэ нь хайлт болон хараагүй хүмүүст зориулсан alt текст болно.
- **Зөвхөн бодит, Монголд авсан, зөвшөөрөлтэй зураг** оруулна. Stock зураг, AI-аар үүсгэсэн зураг, өөр орны зураг ашиглахгүй (`docs/plan/images.md`). Хүн тод харагдах зурагт тэр хүний зөвшөөрөл авна.

## 6. "[ЖИШЭЭ]" entry-ууд

Шинэ төрөл бүрт 2 жишээ entry байгаа. Нэр нь "[ЖИШЭЭ]"-ээр эхэлдэг бөгөөд preview дээр загварыг харуулахад зориулагдсан. Үндсэн сайт дээр харагдахгүй. Тэдгээрийг хуулж засаад шинэ entry хийж болохгүй. **Add entry**-ээр шинээр үүсгэнэ. Go-live-ийн өмнө устгана (`docs/plan/sample-entries.md`).

## 7. Publish хийхээс өмнө шалгах зүйлс

- [ ] Нэр, гарчиг зөв бичигдсэн, "[ЖИШЭЭ]" гэж эхлээгүй.
- [ ] Slug нь латин жижиг үсэг, зураастай, давхардаагүй.
- [ ] Төрөл, сэдэв зөв сонгогдсон.
- [ ] Аймгийн нэр бусад entry-тэй ижил бичигдсэн.
- [ ] Хүн, өрхийн нэр, утас, зургийг нийтлэх **зөвшөөрөл** авсан. Нийтлэлд "Зөвшөөрөл авсан" = Yes.
- [ ] Нотолгоогүй "eco/green" маягийн үг алга. Тэмдэг гаргах талбаруудад зөвхөн бодит мэдээлэл бий.
- [ ] Үнэ, огноо шинэчлэгдсэн.
- [ ] Захиалгын холбоос ажиллаж байна (шинэ таб дээр нээж шалгана).
- [ ] Зураг 1600 px-ээс өргөн, Монголынх, Title бичигдсэн.
- [ ] Холбоос хадгалсан entry-үүд (зохион байгуулагч, үйлдвэрлэгч) publish хийгдсэн.
- [ ] Publish хийсний дараа preview дээр хуудсаа нээж шалгасан.

## 8. Тусламж

- Талбар бүрийн тайлбар Contentful дээр талбарын доор байна.
- Төрлүүдийн тодорхойлолт: `scripts/contentful/01-content-types.ps1`.
- Хуудсуудын загвар: `docs/plan/templates.md`.
