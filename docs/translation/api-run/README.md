## Үргэлжлүүлэх

Цэнэглэсний дараа:

```
node scripts/translation/api-translate.mjs all --model sonnet --budget <нийт зарцуулах дээд хэмжээ> --hard <цэнэг>
```

`budget` ба `hard` нь ledger.json-ийн хуримтлагдсан дүнгээр ($4.462-оос эхэлнэ) тооцогдоно. Жишээ нь $10 цэнэглэвэл
