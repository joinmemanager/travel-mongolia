## Шалгах үед анхаарах (эх текстийн асуудал)

Орчуулгад эхийн баримтыг өөрчлөөгүй. Дараах нь **монгол эх текстэд** засах шаардлагатай байж магадгүй:

1. **Сонгинохайрхан**: «120.1 га нутагтай» — 315,802 хүнтэй дүүрэгт хэт бага (≈1,200 км² байх магадлалтай).
   Орчуулгад "120.1 hectares" гэж эх хэвээр үлдээв.
2. **Налайх**: «220 кВт-ын өндөр хүчдэлийн шугам» — шугамын хүчдэл кВ (киловольт). Орчуулгад "220 kV" гэж
   бичсэн (нэгжийн илэрхий алдаа тул). Эх текстийг засах.
3. **Тэс**: «10 мянган калл дулаан» — "10,000 Gcal" (гигакалори) гэж ойлгож орчуулав. Эхийг шалгах.
4. **Налайх**: «68.8 мянган га буюу 68764 га» — хоёр тоо бага зэрэг зөрүүтэй; "68,800 hectares, or 68,764 hectares
   exactly" гэж хоёуланг үлдээв.

## Итгэлгүй орчуулсан ан амьтан, ургамлын нэр

Англи нэр нь тодорхойгүй нутгийн нэрсийг галигаар үлдээв, мэргэжлийн хүнээр шалгуулах:

- Тэс: **жирх** (jirkh), **нохой зээх** (nokhoi zeekh), **турлиах** (turliakh), **сар** (sar), ургамал **тагш** (tagsh).
- Номгон: **сондуул, загсгал, шаваг, хөмүүл, хэрээний нүд** (галигаар).
- Дадал: «дэрэвгэр жиргэрүү» → large-flowered lady's slipper, «тэхийн шээг» → honeysuckle — шалгах.

## Хэв маягийн сонголтууд (санал өгнө үү)

- H2-ыг асуулт болгосон ("How many people live in Dadal and how is it divided?"). Хэт урт санагдвал богиносгоно.
- "soum" жижиг үсгээр ("Dadal soum"), "District" том үсгээр ("Nalaikh District").
- Байгалийн нэр монгол дарааллаар ("Khuvsgul Lake", "Onon River").
