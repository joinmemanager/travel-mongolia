# Орчуулах заавар (товч)

Contentful-д юу ч бичихгүй. Бүх ажил файлаар явна, Payload бэлэн болоход файлаас нь оруулна.

## 1. Файлаа авах

- Орчуулах хуудсууд: [`docs/translation/batches/`](batches/) — `en-001.md`, `en-002.md`, … (нэг файлд 50 хуудас).
- Эдгээр нь rewrite-list.csv-д «дахин бичсэн» хуудсуудын **ноорог** хувилбар (Contentful-аас нэг удаа татсан
  локал хуулбараас). Одоо: **en-001 … en-019 — 893 хуудас** (11/13 ба 11/16-ны экспорт). Дарааллаар нь орчуулна.
- **en-review-001, en-review-002 — 90 хуудас:** rewrite-list.csv-д «ГАРААР ШАЛГАХ» тэмдэглэгээтэй, монголоороо
  нийтлэгдээгүй хуудсууд. Монгол текстийг нь шалгаж дууссаны дараа орчуулна (эх нь өөрчлөгдвөл орчуулга хуучирна).
  Хариуг `done/en-review-001.md` гэж хадгална, шалгагч ижил.
- Нэг файлаа сонгоод VS Code-оор нээнэ.

## 2. AI-д юу хуулах

1. Файлыг **бүхэлд нь** хуулна (Ctrl+A, Ctrl+C). Эхэнд нь англиар бичсэн заавар (prompt), толь бичиг байгаа —
   түүнийг ч хамт хуулна.
2. Claude (claude.ai) эсвэл өөр AI-ийн шинэ чатад буулгаж илгээнэ.
3. Файл том (15–40 мянган үг) тул хариу дундуур тасарч болно. Тэгвэл: **"Continue from the next @@@ ENTRY."**
   гэж бичээд үргэлжлүүлүүлнэ. Эсвэл файлын хагасыг (хуудсын `@@@ ENTRY` … `@@@ END` бүтэн хэсгээр нь) хуулж
   хоёр удаа явуулж болно — prompt-ийг хоёр удаа хоёуланд нь хуулна.

## 3. Хариуг хаана хадгалах

- AI-ийн хариуг **ижил нэртэй** файлд: `docs/translation/done/en-001.md`.
- Хэд хэдэн хариу бол дарааллаар нь нэг файлд залгана (`@@@ ENTRY`-ээс `@@@ END` хүртэлх бүтэн хэсгүүдээр).
- AI хариуныхаа өмнө/ард тайлбар бичсэн бол түүнийг устгана. Prompt хэсгийг done файлд оруулах шаардлагагүй.

## 4. Шалгагчийг ажиллуулах

`C:\project\teslatraders-payload` хавтсанд терминал нээгээд:

```bash
.tools/node/node.exe scripts/translation/check.js docs/translation/done/en-001.md
```

(Бүх done файлыг нэг дор: `... check.js docs/translation/done`)

Тайлан `docs/translation/done/en-001.report.md`-д гарна:

- **Алдаа** (заавал засна): хуудас/талбар дутуу, `@@@` мөр эвдэрсэн, гарчиг/жагсаалт/зураг/холбоосын тоо эхээс
  өөр, монгол (кирилл) үсэг үлдсэн, seoTitle 60-аас, seoDescription 155-аас урт.
- **Анхааруулга** (уншаад шийднэ): толь бичгийн нэр томъёо олдсонгүй, H2 асуулт биш, урт эхээсээ хэт зөрүүтэй,
  seoDescription богино. Зарим нь худал анхааруулга байж болно (жишээ нь «хавтгай дөрвөлжин км»-ийг «хавтгай» →
  wild camel гэж санах).

Алдааг done файлд гараар засах эсвэл AI-д "Fix: …" гэж зааж засуулаад дахин шалгана. **Алдаа: 0** болбол бэлэн.

## 5. Шалгах (хүн)

Автомат шалгалт утгыг шалгахгүй. Хуудас бүрээс ядаж эхний догол мөр, H2-ууд, SEO хоёр талбарыг уншина.
Хэв маяг: [style-guide.md](style-guide.md). Нэр томъёо: [glossary.csv](glossary.csv) (Excel-ээр нээгдэнэ).
Жишээ болгож [pilot-en/](pilot-en/)-ийн 10 хуудсыг үзнэ үү.

## 6. Payload руу оруулах (Payload бэлэн болсны дараа, Claude хийнэ)

```bash
cd travel-mongolia
node scripts/payload/cli.mjs run scripts/payload/import-translations.ts docs/translation/done/en-001.md
```

Тайландаа «Алдаа: 0» байхгүй бол оруулахгүй. Орчуулга **ноорог** болж орно. Редактор Payload-д шалгаад
нийтлэхдээ «Орчуулга нийтлэгдсэн хэлүүд» талбарт `English`-ийг сонгоход л `/en/...` хуудас нээгдэнэ.

## Анхаар

- `batches/` дахь файлыг гараар засахгүй (шалгагч түүнтэй харьцуулна).
- Шинэ багц гаргах (Claude хийнэ): эхлээд `scripts/payload/export-delta.js` (Contentful-д ≈4 уншилт), дараа нь
  `scripts/translation/export-batches.js`. Орчуулга нь эхэлсэн (done файлтай) багцыг дахин бичихгүй. Скрипт
  rewrite-list.csv-ийг экспорт хийсэн мөчийн төлвөөр уншдаг тул экспортоос хойш дахин бичсэн хуудас хуучин
  текстээрээ багцад орохгүй.
- Хуудсыг Contentful-д дахин засвал орчуулга хуучирна — тэр хуудсыг дараагийн багцад дахин гаргана.
