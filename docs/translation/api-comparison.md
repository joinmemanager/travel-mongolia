## 3. Нэг хэлний зардлын тооцоо

**Google NMT:** 8.3 сая тэмдэгт × $20 = **≈$166 / хэл** (үнэгүй 0.5 сая хасвал ≈$156). Translation LLM ойролцоогоор
ижил (оролт 8.3 сая × $10 + гаралт ≈8 сая × $10 ≈ $160).

**Claude (Batch API):** token-ийн тоо монгол кирилл текстэд **хэмжээгүй — таамаг**: 1 token ≈ 2.5 тэмдэгт гэж
үзвэл оролт ≈3.3 сая token + prompt/толь бичиг (багц бүрт ≈8–10 мянган token, кэшлэгдэнэ) ≈4 сая token; англи
гаралт ≈1.1 сая үг ≈1.6 сая token.

| Загвар (Batch) | Оролт | Гаралт | Нэг хэл | Аюулгүйн нөөц ×2 |
|---|--:|--:|--:|--:|
| Opus 5.5 | 4 сая × $2 = $8 | 1.6 сая × $10 = $16 | **≈$24** | ≈$50 |
| Sonnet 5.5 | 4 сая × $1 = $4 | 1.6 сая × $5 = $8 | ≈$12 | ≈$25 |

Хятад, япон, солонгос хэлний гаралт token-оор урт байх тул эдгээрт ×1.5–2 гэж үзнэ. 5 хэлэнд Opus 5.5-аар
**≈$150–300**, Google NMT-ээр **≈$800**.

**Таамгийг баталгаажуулах:** эхний багцыг илгээхийн өмнө `messages.count_tokens`-оор en-001.md-ийн бодит token-ийг
хэмжинэ (үнэгүй). Тэр тооноос бүх ажлын үнийг дахин тооцно.

## 4. Чанар, хурд

| Шалгуур | Claude (Opus 5.5) | Google NMT |
|---|---|---|
| Толь бичгийн нэр томъёо (556 мөр) | Prompt-д өгнө, дагадаг (пилотод 10/10 хуудас шалгагч давсан) | Advanced v3-ийн glossary ресурс шаардлагатай (тусдаа тохиргоо) |
| Markdown бүтэц, зураг, холбоос хадгалах | Тийм (пилот: бүтцийн алдаа 0) | HTML/текстийг хадгалдаг ч `@@@` тэмдэглэгээ, Markdown escape-ийг эвдэх эрсдэлтэй |
| SEO дүрэм (seoTitle ≤60, description ≤155, H2-ыг асуулт болгох) | Зааврыг биелүүлнэ | **Хийж чадахгүй** — үгчлэн орчуулна, уртыг хянахгүй |
| Монгол эхийн нарийн утга (домог, түүхэн нэр, «Нууц товчоо»-ны нэрс) | Контекстоор сайн; пилотод нэр, ишлэлийг англи уламжлалт хэлбэрээр | Үгчлэл, нэрийг заримдаа утгаар нь орчуулдаг |
| Хурд | Batch: ихэнхдээ 1 цаг дотор, 24 цагийн дээд хязгаар | Шууд (секунд) |
| Хүний шалгалт | Заавал (утгын шалгалт) | Заавал, засах ажил илүү |

Чанарын харьцуулалт нь **пилот болон шаардлагад тулгуурласан дүгнэлт** — Google NMT-ээр ижил 10 хуудсыг
орчуулж харьцуулаагүй (Google Cloud төсөл, түлхүүр шаардлагатай). Шийдвэр гаргахын өмнө 3–5 хуудсыг хоёуланг нь
орчуулж харалган (аль нь гэдгийг нууж) шалгахыг санал болгож байна.

## 5. Зөвлөмж

1. **Claude Opus 5.5 + Batch API** — үндсэн хэрэгсэл. Хямд (Google-ээс ≈5 дахин), SEO болон бүтцийн дүрмийг
   биелүүлдэг, толь бичгийг шууд хэрэглэдэг. Толь бичиг, хэв маягийн зааврыг prompt caching-ээр кэшлэнэ.
2. Хэрэв токен хэмжилтээр зардал хүлээлтээс давбал **Sonnet 5.5**-ийг 5 хуудсан дээр туршиж, чанар хангавал
   ашиглана (хагас үнэтэй).
3. Google NMT-ийг зөвхөн маш их хэмжээний, бүтэцгүй богино текст (жишээ нь зургийн alt) хурдан орчуулахад нөөц
   сонголтоор.
4. Ажлын урсгал (`docs/translation/HOW-TO.md`) аль ч AI-тай ажиллана: одоо гараар (claude.ai), дараа нь Batch API-аар
   автоматжуулна (`ANTHROPIC_API_KEY` хэрэгтэй — 2-р үе шат).
