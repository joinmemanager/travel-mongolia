## 5. Дараагийн алхам

1. Preview дээр дээрх 5 хуудсыг шалгаарай.
2. **Webhook-ийг унтраа** (Contentful → Settings → Webhooks → сайтын revalidate webhook → Disable). Ингэхгүй бол нийтэлсэн entry бүр webhook дуудаж, кэшийг олон дахин шинэчилнэ.
3. Нийтлэх. `docs/plan/rewrite-publish-ids.txt` файлд «дахин бичсэн (draft)» төлөвтэй бүх entry-ийн id (238) бий. Скрипт entry бүрийн ноорог зөвхөн body/description/seoTitle/seoDescription-аар ялгаатай эсэхийг шалгаад нийтэлнэ, өөр талбар өөрчлөгдсөн бол алгасна:
   ```
   node scripts/content/publish-entries.js $(cat docs/plan/rewrite-publish-ids.txt)
   ```
   Зургийн alt (asset title)-ыг мөн ноорог болгосон. Эдгээр asset-ийг Contentful дээр «Publish» хийнэ (жагсаалт: `backups/rewrite-originals/asset-*.json`).
4. Нийтэлж дуусаад **webhook-ийг буцааж асаа**. Дараа нь кэшийг нэг удаа шинэчилнэ (production deploy эсвэл `/api/revalidate`-ийг гараар дуудах).
5. Push: `git push origin main` (rewrite хэрэгсэл, ноорог файлууд, тайлан, ignore-build засвар).
