## 6. Дараагийн алхам

1. Preview дээр дээрх 5 хуудас, гараар шалгах 421, 431-р хуудсыг шалгаарай.
2. **Сүлдний кодын өөрчлөлт.** `page.tsx`, `lib/soumEmblems.ts`-ийг тусдаа branch-д push хийж preview дээр шалгаад, main-д merge хийнэ. Commons-ийн entry-үүдийг нийтлэхээс өмнө энэ код production-д гарсан байх ёстой. Эс тэгвээс сүлд нь тэмдэг болж харагдахгүй.
3. **Webhook-ийг унтраа** (Contentful → Settings → Webhooks → сайтын revalidate webhook → Disable).
4. **Commons asset-уудыг эхэлж нийтэл** (`commons-*` id-тай asset). Дараа нь entry-үүдийг нийтэл:
   ```
   node scripts/content/publish-entries.js $(cat docs/plan/rewrite-publish-ids.txt)
   ```
   Скрипт одоо `image` талбарын өөрчлөлтийг зөвшөөрдөг, дахин бичээгүй сумын нөөцийг `backups/commons-soum-originals/`-оос хайдаг. Commons-оор холбосон боловч дахин бичээгүй сумдын id-г `tmp/soum-photos/c2-state.json`-оос гаргана.
   Зургийн alt (asset title)-ыг мөн ноорог болгосон. Тэдгээрийг «Publish» хийнэ (`backups/rewrite-originals/asset-*.json`).
5. Нийтэлж дуусаад **webhook-ийг буцааж асаа**, кэшийг нэг удаа шинэчил.
6. Push: `git push origin main` (ноорог файлууд, хэрэгсэл, тайлан).
