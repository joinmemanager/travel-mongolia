## 6. Дараагийн алхам

1. Preview дээр дээрх 5 хуудас, ялангуяа «давхар хуудас» болон «аймаг зөрсөн» бүлгийн мөрүүдийг шалгаарай.
2. **Push хийх** (миний хийгээгүй):
   - `git push origin main` — ноорог файлууд, CSV, тайлан.
   - `git push origin feat/soum-commons-emblems` — сүлдний код. Preview дээр шалгаад main-д merge хийнэ. Commons-ийн entry-үүдийг нийтлэхээс өмнө энэ код production-д гарсан байх ёстой.
3. **Webhook-ийг унтраа** (Contentful → Settings → Webhooks → сайтын revalidate webhook → Disable).
4. **Commons asset-уудыг эхэлж нийтэл** (`commons-*`). Дараа нь entry-үүдийг нийтэл:
   ```
   node scripts/content/publish-entries.js $(cat docs/plan/rewrite-publish-ids.txt)
   ```
   Commons-оор холбосон боловч дахин бичээгүй сумдын id-г `tmp/soum-photos/c2-state.json`-оос гаргана. Зургийн alt (asset title)-ын ноорогийг мөн нийтэлнэ.
5. Нийтэлж дуусаад **webhook-ийг буцааж асаа**, кэшийг нэг удаа шинэчил.
6. **Дахин бичих ажлыг үргэлжлүүлэх:** шинэ тоолуурын хязгаартайгаар 1124-р мөрөөс (урт соёл, түүхийн нийтлэлүүд) эхэлнэ. Нэг нийтлэлд илүү их хугацаа, анхаарал шаардлагатай.
7. Алгассан 9 хуудас (366, 369, 1099, 1108, 1114, 1120–1123)-ыг гараар шийдэх.
8. Ажил D дуусахад `tmp/images-enhanced/run-ajil-d.log`-ийн сүүлийн мөрийг шалгаж, Contentful-д солих эсэхийг шийднэ.
