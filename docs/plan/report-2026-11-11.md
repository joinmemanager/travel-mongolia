## 5. Дараагийн алхам

1. Preview дээр дээрх 5 хуудсыг шалгаарай.
2. **Webhook-ийг унтраа** (Contentful → Settings → Webhooks → сайтын revalidate webhook → Disable). Ингэхгүй бол 100 нийтлэл бүр webhook дуудаж, сайтын кэшийг 100 удаа шинэчилнэ.
3. Нийтлэх команд. `docs/plan/rewrite-publish-ids.txt`-д «дахин бичсэн (draft)» төлөвтэй бүх entry-ийн id бий. Скрипт entry бүрийн ноорог нь зөвхөн body/description/seoTitle/seoDescription-аар ялгаатай эсэхийг шалгаад нийтэлнэ, өөр талбар өөрчлөгдсөн бол алгасна:
   ```
   node scripts/content/publish-entries.js $(cat docs/plan/rewrite-publish-ids.txt)
   ```
   Зургийн alt (asset title)-ыг мөн ноорог болгосон. Тэдгээр asset-ийг Contentful дээр «Publish» хийх хэрэгтэй (жагсаалт: `backups/rewrite-originals/asset-*.json`).
4. Нийтэлж дуусаад **webhook-ийг буцааж асаа**, дараа нь нэг удаа бүх кэшийг шинэчлэх (`/api/revalidate`-ийг гараар дуудах эсвэл production deploy).
5. Push: `git push origin main` (кодын өөрчлөлт: rewrite хэрэгслүүд, тайлан).
