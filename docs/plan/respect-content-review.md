# "Хүндэтгэлтэй аялал" текстийн баталгаажуулах жагсаалт (5б)

> Текст: `travel-mongolia/lib/respectData.ts` (НООРОГ). Огноо: 2026-10-05.
> Дүрэм: тоо баримт, хууль, торгуулийн хэмжээг зохиож бичээгүй, "eco", "green" гэх мэт нотолгоогүй шошго хэрэглээгүй.

## Хариуцлагатай аяллын гарын авлага (`/respect`)

Амлалтын 7 заалт нь баримтын мэдэгдэл биш, зөвлөмж тул баталгаажуулах өгүүлбэр байхгүй. Зөвхөн найруулга, өнгө аясыг уншиж засна уу.
